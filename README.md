## 📌 Overview

**Z Player** is a modern Android media player built for people who keep their media locally.

Instead of focusing on streaming services, accounts, or cloud-dependent features, Z Player provides a clean interface for browsing, organizing, and playing your **local video and audio files**.

Built with **Kotlin, Jetpack Compose, Material 3, Room, and libmpv**, Z Player combines a modern interface with a powerful playback engine while keeping your media and playback data on your device.

---

## ✨ Key Features

### 🎬 Powerful Local Playback

- **libmpv-powered playback engine**
- Wide media format and codec compatibility
- Multiple audio track support
- Subtitle support
- Audio and subtitle delay controls
- Resume playback from saved position
- Next / previous media navigation
- Intro & outro skipping
- Custom playback speed
- Picture-in-Picture support

### 🎛️ Advanced Playback Controls

- Smooth and precise seeking
- Brightness and volume gestures
- Playback speed controls
- Direct aspect ratio selection
- Audio track selection
- Subtitle selection and synchronization
- One-handed playback controls

### 📚 Smart Media Library

- **Continue Watching** for unfinished videos and episodes
- **Recently Added** for newly discovered media
- Folder and library browsing
- Background media scanning
- Playback history
- Favorites
- Playlist support
- Hidden files and folders support
- Customizable library navigation

### 🎨 Modern Interface

- Material 3 design
- Card-based media browsing
- Hero preview banners
- Adaptive system theming
- Dynamic colors
- Light and dark themes
- Clean, minimal navigation
- Responsive layouts for phones and tablets

### 🔐 Privacy & Security

- Local-first design
- No account required
- No cloud media library required
- **Private Vault**
- **Vault Lock**
- **App Lock**
- Local playback history and progress

### ⚙️ Useful Tools

- 🔎 Settings Search
- 📖 Built-in User Guide
- 🌍 Multiple language support
- 💾 Storage information
- Customizable playback and library settings

---

## 🚀 Powered by libmpv

Z Player uses **libmpv** as its playback engine.

libmpv provides a powerful and flexible foundation for handling different media formats, codecs, subtitles, audio tracks, playback controls, and advanced playback features.

The goal is simple:

> **Your media. Your player. Your way.**

## 📥 Installation

1. Open the [**Releases**](https://github.com/silenTKnight-sudo506/ZPlayer/releases) page.
2. Download the appropriate APK for your device.
3. Install the APK.
4. Open Z Player and grant the required media permissions.

### APK Architectures

| APK | Architecture | Recommended For |
|---|---|---|
| **arm64-v8a** | 64-bit ARM | Most modern Android phones and tablets |
| **armeabi-v7a** | 32-bit ARM | Older ARM devices |
| **x86_64** | 64-bit x86 | x86_64 Android devices and emulators |
| **x86** | 32-bit x86 | Older x86 devices and emulators |
| **Universal** | Multiple architectures | Recommended if you're unsure |

## 🔒 Privacy

Z Player is designed around **local media and local data**.

Your videos, audio files, playback history, playlists, favorites, and resume progress remain on your device unless you explicitly move or share them.

Z Player does not require an online account or cloud media library for its core functionality.
