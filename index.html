Z Player

A modern, fast Android media player built with card UI layouts, hero previews, and fluid gesture controls.

Download APK GitHub Repo

Key Features

🎨 Card-Driven UI

Replaces plain text file trees with rich media cards and hero preview banners.

⚡ Hardware Acceleration

Low CPU overhead ensuring smooth, high-bitrate media decoding.

📱 Gesture Shortcuts

Intuitive drag controls for fast seeking, brightness, and volume adjustments.

📁 Visual Navigation

Easily toggle between visual hero cards or quick structured folder access.
